# Trade Journey V2.4

Private local trading journal based on V2.3.

## Added in V2.4
- Advanced Analytics: strategy-wise, asset-wise and session-wise performance
- Equity Curve: cumulative R curve with current/peak/low stats
- Trading Heatmap: weekday x time-block performance (00–06, 06–12, 12–18, 18–24)
- Psychology Tracker: emotion before/after trade plus psychology note
- Psychology is shown in trade details and analytics
- Existing V2.3 colorful sidebar, custom colors, themes, optional chart uploads, calendar, edit/delete and local backup remain

Open `index.html` in a browser. Data remains local to that browser via localStorage.
